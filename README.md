# Word Counter and Text Analyzer

## Project Overview
This is a Python-based Word Counter and Text Analyzer project. It reads text from a file and generates an analysis report containing the total word count and other text statistics.

## Project Features
- Reads text from a file.
- Counts the total number of words.
- Analyzes the given text.
- Generates a text analysis report.
- Displays useful text statistics.

## Technologies Used
- Python

## Project Structure
- **Codebase:** Contains the project source code.
- **Testcases:** Contains project test cases.
- **sample.txt:** Contains sample input text.

## How It Works
1. The program reads text from the input file.
2. It processes the given text.
3. It performs word counting and text analysis.
4. It generates an analysis report.
